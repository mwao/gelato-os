### 1. 출퇴근 기록 삭제 (`useAttendance.ts` + `PersonRow`)

**요구사항**
- 수정 모드에서 «삭제» 버튼을 누르면 해당 출퇴근 행(`attendance`)을 DB에서 삭제.
- 삭제 전 `confirm` 다이얼로그로 실수 방지.
- 삭제 성공 시 editMode 닫힘 + `['attendance']` 쿼리 무효화.

**구현**
- `useAttendance.ts`: `useDeleteAttendance` mutation 추가.
  - `.delete().eq('id', attendanceId).eq('store_id', storeId)` — store_id 이중 검증.
  - `onSuccess`: `invalidateQueries(['attendance'], refetchType:'active')`.
- `StaffPage.tsx` `PersonRow`:
  - `useDeleteAttendance` import + 훅 연결.
  - `handleDeleteRecord()`: confirm → `deleteAttendance.mutateAsync(editableId)` → setEditMode(false).
  - 수정 모드 인라인 행에 **삭제** 버튼(destructive variant) 추가(저장·취소 오른쪽).
  - 저장·삭제 pending 중 양쪽 버튼 모두 `disabled`.

### 2. Phase 9 — 급여 & 정산

#### SQL 마이그레이션 (`supabase/sql/feature4_payroll.sql`)

- `payroll` 테이블 생성 + RLS.
- 핵심 컬럼: `period_start(date)`, `period_end(date)`, `base_pay`, `allowances`, `deductions`, `total`, `work_minutes(int)`, `note`, `confirmed(bool)`.
- UNIQUE 제약: `(store_id, staff_id, period_start)` — 직원×월 중복 방지.
- RLS: 설계 원칙 표준 패턴 (`store_id IN (SELECT id FROM stores WHERE owner_id = auth.uid())`).

#### 훅 (`src/hooks/usePayroll.ts`)

- `usePayrollList(periodStart)` — 월별 저장된 급여 목록 조회.
- `useAttendanceWorkSummary(from, to)` — 기간 내 실근무 분(work_minutes) 직원별 집계.
  - `is_baseline = false`, `check_out IS NOT NULL` 조건으로 실적만 집계.
- `useUpsertPayroll` — 저장/갱신 (UPSERT on conflict `(store_id, staff_id, period_start)`).
- `useDeletePayroll` — 저장된 급여 레코드 삭제.

#### 페이지 (`src/pages/PayrollPage.tsx`)

- **월 선택**: `<input type="month">` — 기본값 이번 달.
- **전체 계산 버튼**: 해당 월 attendance 집계 → 직원별 `base_pay = work_minutes / 60 × hourly_rate` 계산 → 미리보기 반영.
- **직원별 행**: 이름 / 시급 / 근무시간 / 기본급 / 수당(수동 입력) / 공제(수동 입력) / 지급액 / 확정여부 / 저장·삭제.
- **미결 표기**: 주휴·야간 수당 자동화는 미결 사항 — 수당 칸 수동 입력 + 안내 문구.
- 확정(`confirmed`) 토글: 확정 후 수정 불가(read-only 처리).

#### 라우트 & LNB

- `App.tsx`: `/payroll` 라우트 추가.
- `AppLayout.tsx`:
  - `NavSoon` → `NavLink` 로 전환 (급여 및 정산 활성화).
  - `pageTitle` 매핑에 `/payroll` 추가.
  - 로그아웃 시 `['payroll']` 쿼리 제거 추가.
