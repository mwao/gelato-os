### 2. Phase 9 — 급여 & 정산 구현

#### DB 마이그레이션 (`supabase/sql/feature4_payroll.sql`)

```sql
CREATE TABLE IF NOT EXISTS payroll (
  id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  store_id     uuid NOT NULL REFERENCES stores(id) ON DELETE CASCADE,
  staff_id     uuid NOT NULL REFERENCES staff(id) ON DELETE CASCADE,
  period_start date NOT NULL,
  period_end   date NOT NULL,
  base_pay     numeric NOT NULL DEFAULT 0,
  allowances   numeric NOT NULL DEFAULT 0,
  deductions   numeric NOT NULL DEFAULT 0,
  total        numeric NOT NULL DEFAULT 0,
  work_minutes integer NOT NULL DEFAULT 0,
  note         text,
  confirmed    boolean NOT NULL DEFAULT false,
  created_at   timestamptz DEFAULT now(),
  updated_at   timestamptz DEFAULT now(),
  UNIQUE (store_id, staff_id, period_start)
);

ALTER TABLE payroll ENABLE ROW LEVEL SECURITY;

CREATE POLICY "store owner full access" ON payroll
  USING  (store_id IN (SELECT id FROM stores WHERE owner_id = auth.uid()))
  WITH CHECK (store_id IN (SELECT id FROM stores WHERE owner_id = auth.uid()));
```

> ⚠️ Supabase SQL Editor에서 직접 실행 필요 (자동 마이그레이션 아님)

```ts
function rowTintClass(inStatus, outStatus): string {
  if (inStatus === '지각' || outStatus === '조퇴') return 'bg-destructive/[0.04]'
  if (outStatus === '연장근무') return 'bg-amber-500/[0.05]'
  if (inStatus === '조기출근') return 'bg-sky-500/[0.04]'

  return ''
}
```

### 7. 출퇴근 — 오늘 타임라인 간트 차트 (`TodayGanttChart`)

**변경 파일**: `src/pages/StaffPage.tsx`

오늘 섹션 테이블 위에 바 그래프 형태의 타임라인 차트를 추가.  
예정 스케줄이 있는 직원이 1명 이상일 때만 렌더되며, 전원 휴무인 날은 차트 미표시.

#### 컴포넌트 구조

```
┌─────────┬──────────────────────────────────────────────────────┐
│  이름    │  9시  10시  11시  12시  13시  14시  ...              │
├─────────┼──────────────────────────────────────────────────────┤
│  이정현  │       [████████████████░░░░░░░░░░]                  │ ← 예정
│         │           [████████████]                             │ ← 실제
├─────────┼──────────────────────────────────────────────────────┤
│  이진경  │                          [████████████████░░]       │
└─────────┴──────────────────────────────────────────────────────┘
                    예정 ■  실제 ■  현재 시각 |
```

#### 구현 내용

- **X축 범위 자동 계산**: 전체 예정 직원의 `startHm`/`endHm` 최솟값·최댓값 → `minHour`(floor)~`maxHour`(ceil) 자동 산출.
- **예정 바**: `bg-primary/10 ring-1 ring-inset ring-primary/30` — 연한 배경에 테두리.
- **실제 바**: `bg-primary/60` — 예정 바 위에 오버레이. 퇴근 미기록 시 4px 점으로 표시.
- **현재 시각 선**: X축 범위 안에 있을 때만 `bg-rose-500/60` 세로선 렌더.
- **격자 선**: 시간 단위 수직선 (`bg-border/25`).
- **범례**: 하단 `예정 / 실제 / 현재 시각` 아이콘 — 현재 시각은 범위 내일 때만 표시.
- `pct(m)` 헬퍼: 분(minute) → `[0, 100]` 퍼센트 변환 (clamp 포함).
- `min-w-[320px]`로 소형 화면에서도 스크롤 가능.
