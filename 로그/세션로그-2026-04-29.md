## v1.1 추가 갱신 — 인력·근무표 UX 개선

- **직원 목록 테이블**: 열을 `이름 / 연락처 / 고용형태 / 근무요일 / 급여`로 변경. 고용형태는 매니저·직원·아르바이트 + **형태 등록** 확장. 근무요일은 요일 + 오픈·미들·마감 다줄 표기(`workRules`).
- **직원 상세**: 이름 클릭 또는 **+ 직원 등록** 시 동일 폼. 필드: 이름·연락처·사진·이력서·보건증 파일·보건증 만료일·고용형태·고용일·근무 기간(자동)·근무요일 편집·월 달력에서 일별 근무 형태 순환 입력.
- **근무표 탭**: (1) 주간 — 시간대 세로·요일별 근무자 `<select>`. (2) 월간 — 직원 × 일자별 오픈/미들/마감 `<select>`.
- **Escape**: 직원 상세 열린 상태에서 `Esc` 시 상세 닫기.
- **샘플 데이터 보강**: 고용형태 «인턴» 1건, 직원별 이력서·보건증 파일명·달력 일부 일자, 주간 `WEEK_GRID` 다수 슬롯, 월간 `MONTH_SHIFT`, 출퇴근 `ATT_HISTORY` 추가 행, 급여 당일 매출 샘플 `428000`, 3월 `WORK_MONTH` 2건.
- **설계 문서 반영**: `employment_types`, `staff` 확장 컬럼, `staff_default_shifts`, `staff_calendar_assignments`, `schedule_week_slots`, `schedule_month_cells` 및 프로토타입 매핑 표 추가.

## v1.3 세션 — 근무표 고도화·예정 vs 실제 근무 구현

### 이번 세션에서 한 일

- **신규 파일** `gelato-management-prototype-v1.3.html` 작성 (v1.2 기반, 6가지 기능 추가).

#### 1. 인력관리 — 근무표

**1-1) 주간 근무표: 과거 시간대 잠금**
- `isWeekCellPast(d, s)`: 현재 시각보다 이른 슬롯 판별.
- 과거 셀: `class="wk-cell past"` → 회색 배경·`cursor:not-allowed`. 이벤트 핸들러 미삽입.

**1-2) 주간 근무표: 단건(셀 내 ×) 삭제**
- 기존 «지우기» 전체 삭제 → **이름 chip 옆 `×` 버튼**으로 단건 삭제.
- `removeWeekChip(event, d, s, staffId)`: 해당 staffId만 배열에서 제거.
- 과거 셀 chip에는 × 버튼 미표시.

**1-3) 월간 근무표: "월별 기본 근무 세팅" 버튼**
- `applyMonthDefaultSchedule()`: `workRules[{dow, shift}]` 순회 → 해당 월 전체 요일 매핑.
- 기존 수동 편집 데이터 덮어씀 (confirm 후 적용).
- `MONTH_SHIFT` + `staff.calendar[ym][day]` 양방향 갱신 후 `renderMonthShiftTable()` 호출.

**1-4) 월간→주간 연동: chip 색상**
- `chipShiftClass(staffId, d)`: `WEEK_DATES[d]`로 날짜 추론 → `MONTH_SHIFT` 조회 → 오픈=초록/미들=파랑/마감=주황.
- `renderWeekVerticalGrid()` 및 `updateWeekCell()` 호출 시 chip에 색상 적용.

**1-5) 주간 근무표→출퇴근 기준 데이터 생성**
- 「📋 출퇴근 기준 데이터 생성」 버튼 추가 (주간 근무표 카드 우측).
- `generateAttBaseline()`: 슬롯별 직원 순회 → 첫 슬롯=출근, 마지막 슬롯+1h=퇴근 → `ATT_HISTORY` 삽입 (`_baseline:true`).
- 동일 날짜·직원 기록 존재 시 스킵.

#### 2. 예정 스케줄 vs 실제 근무 — 설계 보충 및 부분 구현

**2-1) 출퇴근 탭: 이전/오늘 데이터만 표시**
- `renderTA()`: 미래 날짜(기준 데이터 등) 제외. 이전 기록 최대 10건 역순. `_baseline` 배지 구분.

**2-2) 급여 및 정산: 서브탭 추가**
- **서브탭**: `정산 조건` / `근무 시간` (`.payroll-subtabs`)
- **정산 조건 탭**: 기본급 기준을 실출퇴근 합산(`actualHoursForStaff()`)으로 변경. 실근무 있으면 `ATT_HISTORY` 우선, 없으면 `WORK_MONTH` fallback. `pr-actual-hours` 행으로 산출 근거 시각화.
- **근무 시간 탭**: 조회 월·직원 필터, `renderWorkhoursTab()` 구현.
  - 상세 테이블: 직원·날짜·예정 시프트·실제 출근·퇴근·실근무h.
  - 요약 테이블: 직원별 출퇴근 건수·실근무 합계·기본급 산출.
- **예정 vs 실제 비교**: `getPlannedTimesForDate(staffId, dateStr)`로 WEEK_GRID 예정 시간 조회 → `diffMinutes()` 비교.
  - 5분 초과 지각: 🔴 `diff-late`, 5분 초과 조퇴: 🔵, 정상: ✅ `diff-ok`, 근무표 미배정: 안내 텍스트.

### 발생한 문제 및 해결

- `week-chip-del` 버튼이 부모 셀의 `mousedown` 트리거 → `e.stopPropagation()` 처리.
- 과거 셀 chip × 버튼 비노출 조건 추가.
- `payroll-stat-total` 계산 실근무 기반 변경 시 `sumMonthPayroll()`도 `payrollForStaff()` 재사용하도록 통일.

## v1.4 세션 — 출퇴근 UI 개선·근무 시간 탭 기간 조회

### 이번 세션에서 한 일

- **신규 파일** `gelato-management-prototype-v1.4.html` 작성 (v1.3 기반, 5가지 기능 수정).

#### 1. 인력관리 — 출퇴근 탭

**1-1) 이전 기록: 날짜별 그룹핑 + 달력 아이콘 날짜 이동**
- 기존의 단순 리스트 방식 → **날짜 그룹 블록(`.ta-date-group`)** 형태로 전면 교체.
- 탭 상단에 날짜 선택 date input 추가 (`ta-date-filter`). 날짜를 선택하면 해당 날짜 기록만 필터링, 「전체 보기」 버튼으로 리셋.
- 기존의 모호한 「기준」 뱃지 제거 — `_baseline` 데이터는 이전 기록에서 표시하지 않음 (미래 예정 데이터이므로).
- 날짜별 헤더에 📅 달력 아이콘 + 날짜·요일 표시.

**1-2) 근무자당 예정/실제 2행 표시 — 이전 기록 + 오늘 공통 적용**
- 각 근무자별 카드 블록(`.ta-person-block`) 구조 도입.
  - **예정 행** (파란 뱃지): 주간 근무표 슬롯 → 예정 출근~퇴근 시간 (없으면 월간 시프트 기반 추정).
  - **실제 행** (초록 뱃지): 실제 출근~퇴근 시간 (빈값이면 「아직 빈값」 텍스트).
- 이전 기록 예시: `김지수 — 예정: 2026-04-28 08:00 ~ 13:00 / 실제: 07:55(출근) ~ 13:30(퇴근)`.
- 오늘 예시: 오픈 체크 전이면 `실제: 미출근`, 출근 체크 후 퇴근 전이면 `~ [ 아직 빈값 ]`.
- 지각 여부 `diffTag`를 실제 행 우측에 인라인 표시.

**1-3) 주간 근무표 「출퇴근 기준 데이터 생성」 버튼 설명 수정**
- 버튼 title 및 힌트 텍스트를 「월간 근무표의 오픈/미들/마감 색상 세팅」 역할로 명확히 재기술.

#### 2. 급여 및 정산 — 근무 시간 탭

**2-1) 조회 기간 (시작~종료) 입력으로 변경**
- 기존 `input[type=month]` 단일 월 선택 → **조회 시작일 + 조회 종료일** 두 개의 `input[type=date]`로 교체.
- 기본값: 현재 월 기준 (2026-04-01 ~ 2026-04-30). 시작·종료 둘 다 독립 조정 가능.
- 범위 레이블(`wh-range-label`)에 `시작일 ~ 종료일` 형식으로 표시.
- 요약 테이블도 동일 기간 기준으로 합산.

**2-2) 직원별 근무 시간 상세 테이블에 예정 출근·예정 퇴근 열 추가**
- 컬럼 순서: `직원 / 날짜 / 예정 시프트 / 예정 출근 / 예정 퇴근 / 실제 출근 / 실제 퇴근 / 실근무h / 예정 비교`.
- 예정 출근·퇴근은 주간 근무표(`WEEK_GRID`) 슬롯 데이터 기준 (`getPlannedTimesForDate()`).
- `_baseline` 뱃지 컬럼 제거 (기준 데이터는 근무 시간 탭에서도 제외하지 않되 별도 표기 없음).

### 발생한 문제 및 해결

- 구 `renderTA()` 함수가 새 함수 추가 후 중복 선언 → 구 함수 제거.
- `todayStr()` / `nowHM()` 이 renderTA 앞 위치에서 삭제되어 참조 오류 발생 → 새 renderTA 함수 바로 앞에 재위치.
- `payroll-month` oninput에 `renderWorkhoursTab()` 직접 호출이 있었으나 `wh-month` DOM이 없어 오류 → 호출 제거 (근무 시간 탭은 독립 기간 조회).

- **`INGREDIENTS`**: 12개 재료 (원재료 8 + 부자재 4). `{id, name, unit, unitPrice, category}`.
- **`INVENTORY`**: 재료별 재고 현황. `{ingredientId, qty, minThreshold, purchaseUrl}`.
  - 샘플: 말차 파우더 180g (최소 200g 미달), 컵(L) 120개 미달, 포장 백 85개 미달.
- **`INV_TRANSACTIONS`**: 입출고 이력. `{id, ingredientId, type:'in'|'out'|'discard', qty, reason, staffId, date, time}`.
- **`RECIPE_INGR`**: 레시피별 재료 사용량 (1통 기준). 피스타치오·바닐라밀크·다크초콜릿·딸기소르베·유자소르베 5종.

#### 3. 재고 관리 페이지 (`page-inventory`)

- **상단 Stats**: 총 재료 / 재고 부족(빨강) / 이번 달 입고 건수 / 이번 달 폐기 건수.
- **탭 구조**: 재고 현황 | 입출고 내역 | 폐기 기록.

**재고 현황 탭**
- 분류 필터 버튼 (전체 / 원재료 / 부자재).
- ⚠ 부족만 보기 토글.
- 테이블: 재료명 / 분류 / 단위 / 현재 수량 + 바 차트 / 최소 재고 / 상태 배지(정상·주의·부족) / 구매처(링크 or 등록 버튼).
- 우측 버튼: `+ 입고`, `− 출고`, `🗑 폐기`.

**입출고 내역 탭**
- 재료·유형 필터 (전체/입고/출고/폐기).
- 테이블: 날짜 / 시간 / 재료 / 유형 배지 / 수량 / 사유 / 담당자.

**폐기 기록 탭**
- 폐기 항목만 카드 리스트.
- `🗑 폐기 입력` 버튼.

#### 4. 입출고/폐기 모달

- 재료 선택 / 수량 / 구매처 URL(입고 시 선택) / 사유 / 담당자.
- 저장 시 `INVENTORY` 수량 즉시 반영 + `INV_TRANSACTIONS` 기록 추가.
- 출고 시 재고 초과 확인 다이얼로그.

#### 5. 생산 기록 연동 (`saveProdLog`)

- 생산 플레이버·통 수 선택 → **재료 차감 미리보기** (각 재료별 필요량 / 현재량 / 부족 여부 표시).
- 기록 저장 버튼 클릭 시 `RECIPE_INGR` 기준으로 `INVENTORY` 자동 차감.
- 차감 내역이 `INV_TRANSACTIONS`에 `type:'out'`으로 기록.
- 저장 후 `refreshInvStats()` 및 재고 현황 테이블 리렌더.
- 생산 담당자 셀렉트에 `STAFF` 데이터 연동.
