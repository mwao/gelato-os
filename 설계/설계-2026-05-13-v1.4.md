# 젤라또 가게 운영앱 설계 — v1.4

> 작성일: 2026-05-13  
> 이전 버전: [[설계-2026-05-04-v1.3]]  
> 변경 범위: **Feature 3·4 — 직원·알바 급여 모드 분리**. v1.3 스키마를 베이스로 4개 테이블에 컬럼/객체 추가.

---

## 0. 이 문서가 다루는 것

v1.3까지 `staff`는 **시급 단일 모드**만 지원했다. 본 v1.4는 직원·매니저(월급제)와 아르바이트(시급제)를 **하나의 통합 UI**로 관리하면서 내부 계산 로직만 분기하는 설계를 정리한다.

| 영역 | v1.3 → v1.4 변경 |
|---|---|
| `employment_types` | `pay_mode`, `monthly_off_days` 컬럼 추가 |
| `staff` | `base_salary` 컬럼 추가 |
| `staff_shift_overrides` | **신규 테이블** — 알바 개인별 시프트 시간 |
| `payroll` | `pay_mode`, `bonus`, `off_days_*` 컬럼 추가 |
| 프론트엔드 | `getShiftSlotsForStaff` 헬퍼, `calcPay` 분기 함수, 프로필 폼 분기 UI |

---

## 1. 핵심 설계 원칙 (v1.3에서 계승)

1. `store_id` 모든 비-`stores` 테이블 1열 — SaaS 확장 대비
2. RLS 모든 테이블에 처음부터
3. 예정(plan) ≠ 실적(actual): `schedule_*` ≠ `attendance`. 급여는 실적 기준
4. 재료의 단일 소스: `ingredients` ↔ 재고
5. 원가 계산은 프론트 순수 함수
6. Supabase 쿼리는 TanStack Query 훅으로 래핑

**v1.4 추가 원칙**:

7. **staff 종류 분기는 `employment_types.pay_mode`만으로 결정** — `staff` 마스터에 종류 플래그 중복 금지
8. **시프트 시간 해석은 단일 헬퍼**(`getShiftSlotsForStaff`) — 근무표·출퇴근 baseline·급여 산정 어디서든 같은 함수 사용
9. **급여 산정 결과는 스냅샷** — `payroll.pay_mode` 등 산정 당시 값 보존, 마스터 변경에 영향 안 받음

## 2. DB 스키마 변경

### 2.1 `employment_types` 확장

```sql
ALTER TABLE employment_types
  ADD COLUMN pay_mode text NOT NULL DEFAULT 'hourly'
    CHECK (pay_mode IN ('hourly','salary')),
  ADD COLUMN monthly_off_days int;
```

| 컬럼 | 설명 |
|---|---|
| `pay_mode` | `'hourly'` = 시급제(알바), `'salary'` = 월급제(직원·매니저) |
| `monthly_off_days` | `salary`일 때 의무 휴무일수 (보통 8). `hourly`에선 NULL |

**기본 시드 데이터**:
```sql
INSERT INTO employment_types (store_id, code, label, pay_mode, monthly_off_days) VALUES
  (?, 'fulltime',  '정규직',  'salary', 8),
  (?, 'manager',   '매니저',  'salary', 8),
  (?, 'parttime',  '파트타임', 'hourly', NULL),
  (?, 'shortterm', '단기',    'hourly', NULL);
```

### 2.2 `staff` 확장

```sql
ALTER TABLE staff ADD COLUMN base_salary numeric;
```

| 컬럼 | 사용 시점 |
|---|---|
| `hourly_rate` (기존) | `pay_mode='hourly'`일 때만 |
| `base_salary` (신규) | `pay_mode='salary'`일 때만 |

> 상여금은 의도적으로 `staff`에 두지 않음. 매월 다르므로 `payroll.bonus`에 행 단위 저장.

### 2.3 `staff_shift_overrides` (신규)

```sql
CREATE TABLE staff_shift_overrides (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  store_id uuid NOT NULL REFERENCES stores(id) ON DELETE CASCADE,
  staff_id uuid NOT NULL REFERENCES staff(id) ON DELETE CASCADE,
  shift text NOT NULL CHECK (shift IN ('open','middle','close')),
  start_slot_index int NOT NULL,
  end_slot_index int NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  CHECK (end_slot_index > start_slot_index),
  UNIQUE (staff_id, shift)
);

ALTER TABLE staff_shift_overrides ENABLE ROW LEVEL SECURITY;

CREATE POLICY "store owner only" ON staff_shift_overrides
USING (
  store_id IN (
    SELECT id FROM stores WHERE owner_id = auth.uid()
  )
);
-- WITH CHECK 정책도 동일 (INSERT용)
```

**의미**:
- 알바 김아무개의 오픈 시간이 매장 기본(09:00~14:00)과 다르게 (10:00~14:00)이면 (staff_id=김, shift='open', start=1, end=5) 행 1개
- (staff_id, shift) UNIQUE → 한 사람의 한 시프트는 정확히 한 시간대

### 2.4 `payroll` 확장

```sql
ALTER TABLE payroll
  ADD COLUMN pay_mode text CHECK (pay_mode IN ('hourly','salary')),
  ADD COLUMN bonus numeric DEFAULT 0,
  ADD COLUMN off_days_used int,
  ADD COLUMN off_days_required int,
  ADD COLUMN off_days_warning text CHECK (off_days_warning IN ('shortage','excess'));
```

| 컬럼 | 산출 방식 | 비고 |
|---|---|---|
| `pay_mode` | 산정 시점 `employment_types.pay_mode` 복사 | 스냅샷 |
| `base_pay` (기존) | salary: `staff.base_salary`<br>hourly: `hourly_rate × 실근무시간` | |
| `bonus` (신규) | salary: 매월 사용자 입력<br>hourly: 항상 0 | UI 인라인 편집 |
| `allowances` (기존) | salary: 0 (기본급 포함 가정)<br>hourly: 주휴·야간 등 법정수당 합 | |
| `off_days_used` | `attendance`에서 휴무일수 카운트 (해당 월) | salary만 |
| `off_days_required` | `employment_types.monthly_off_days` 스냅샷 | salary만 |
| `off_days_warning` | `used < required` → `'shortage'`<br>`used > required` → `'excess'`<br>같음 → NULL | salary만, 표시용 |
| `total` (기존) | `base_pay + bonus + allowances` | |

## 3. 핵심 헬퍼: `getShiftSlotsForStaff`

**파일**: `src/lib/shiftResolver.ts` (신규)

```ts
import type { StoreShiftSettings } from './types';

export interface StaffShiftOverride {
  staff_id: string;
  shift: 'open' | 'middle' | 'close';
  start_slot_index: number;
  end_slot_index: number;
}

export interface ShiftSlots {
  startSlot: number;
  endSlot: number;
}

const DEFAULT_SHIFT_DURATION = 5; // 5슬롯 = 5시간 (매장 기본값에 end가 없을 때 폴백)

export function getShiftSlotsForStaff(
  staffId: string,
  shift: 'open' | 'middle' | 'close',
  storeSettings: StoreShiftSettings,
  overrides: StaffShiftOverride[],
): ShiftSlots {
  // 1순위: 개인 오버라이드
  const o = overrides.find(x => x.staff_id === staffId && x.shift === shift);
  if (o) {
    return { startSlot: o.start_slot_index, endSlot: o.end_slot_index };
  }
  // 2순위: 매장 기본값
  const startSlot = storeSettings[`${shift}_anchor_slot_index` as const];
  return {
    startSlot,
    endSlot: startSlot + DEFAULT_SHIFT_DURATION,
  };
}
```

**사용처**:
- `plannedFromWeek.ts` — 주간 슬롯 → 예정 startHm/endHm 계산
- `useGenerateAttendanceBaseline` — staff별 baseline `check_in/check_out` 생성
- `useAttendanceStatus` — 예정 vs 실적 비교 (지각·조기퇴근 판정)
- `calcPay` — 알바 법정수당 산정 시 야간 시간 포함 여부

## 4. 급여 계산 (`lib/payroll.ts`)

```ts
interface CalcPayInput {
  staff: Staff;
  type: EmploymentType;
  attendance: Attendance[];  // 해당 월, is_baseline=false만
  period: { start: Date; end: Date };
  manualBonus?: number;       // 직원만 사용
}

interface PayrollRow {
  pay_mode: 'salary' | 'hourly';
  base_pay: number;
  bonus: number;
  allowances: number;
  off_days_used: number | null;
  off_days_required: number | null;
  off_days_warning: 'shortage' | 'excess' | null;
  total: number;
}

export function calcPay(input: CalcPayInput): PayrollRow {
  const { staff, type, attendance, period, manualBonus = 0 } = input;

  if (type.pay_mode === 'salary') {
    const offDays = countOffDays(staff.id, attendance, period);
    const required = type.monthly_off_days ?? 8;
    const warning =
      offDays < required ? 'shortage' :
      offDays > required ? 'excess'   : null;

    return {
      pay_mode: 'salary',
      base_pay: staff.base_salary ?? 0,
      bonus: manualBonus,
      allowances: 0,
      off_days_used: offDays,
      off_days_required: required,
      off_days_warning: warning,
      total: (staff.base_salary ?? 0) + manualBonus,
    };
  }

  // hourly
  const hours = sumActualHours(staff.id, attendance, period);
  const basePay = (staff.hourly_rate ?? 0) * hours;
  const holiday = calcHolidayPay(hours, staff.hourly_rate ?? 0);
  const night = calcNightPay(attendance, staff.hourly_rate ?? 0);

  return {
    pay_mode: 'hourly',
    base_pay: basePay,
    bonus: 0,
    allowances: holiday + night,
    off_days_used: null,
    off_days_required: null,
    off_days_warning: null,
    total: basePay + holiday + night,
  };
}
```

### `countOffDays` 정의

해당 월의 날짜 중 `attendance` (is_baseline=false) 레코드가 없는 날의 수. 단, 입사 전·퇴사 후는 제외.

> 더 엄밀하게는 `schedule_month_cells`에서 shift가 NULL인 셀의 수로 정의할 수도 있음 (예정 기준). v1.4 1차 구현은 attendance 기준, 추후 결정.

# v1.4-r1 — SQL 구현 반영 (2026-05-13 추가)

`supabase/sql/feature5_pay_mode.sql` 작성 과정에서 v1.3·v1.4 본문 일부가 **실제 DB 스키마와 불일치**함을 발견. r1은 본문을 덮어쓰지 않고 **차이점을 명시적으로 기록**한다.

## 발견된 불일치

| 항목 | v1.3·v1.4 본문 | 실제 코드 (`feature3_store_shift_settings.sql`) |
|---|---|---|
| 매장 시프트 시간 저장 위치 | `store_shift_settings` 별도 테이블 | `stores` 테이블에 컬럼 6개 인라인 |
| 매장 시프트 시간 단위 | `*_anchor_slot_index int` (슬롯 인덱스) | `shift_*_start text` / `shift_*_end text` (HH:MM) |

→ `staff_shift_overrides`도 실제 컨벤션에 맞춰 **HH:MM 텍스트**로 정의했다.

## §2.3 수정 — `staff_shift_overrides` 확정 스펙

본문 §2.3의 `start_slot_index int` / `end_slot_index int` 표기는 **폐기**. 확정 스펙:

```sql
CREATE TABLE staff_shift_overrides (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  store_id    uuid NOT NULL REFERENCES stores(id) ON DELETE CASCADE,
  staff_id    uuid NOT NULL REFERENCES staff(id) ON DELETE CASCADE,
  shift       text NOT NULL CHECK (shift IN ('open','middle','close')),
  start_time  text NOT NULL,                   -- HH:MM
  end_time    text NOT NULL,                   -- HH:MM
  created_at  timestamptz NOT NULL DEFAULT now(),
  updated_at  timestamptz NOT NULL DEFAULT now(),
  CHECK (start_time ~ '^[0-2][0-9]:[0-5][0-9]$'),
  CHECK (end_time   ~ '^[0-2][0-9]:[0-5][0-9]$'),
  CHECK (end_time > start_time),
  UNIQUE (staff_id, shift)
);
```

| 컬럼 | v1.4 본문 | r1 확정 |
|---|---|---|
| 시작 | `start_slot_index int` | `start_time text` (HH:MM) |
| 종료 | `end_slot_index int` | `end_time text` (HH:MM) |
| 시간순 보장 | `CHECK (end_slot_index > start_slot_index)` | `CHECK (end_time > start_time)` (텍스트 사전순 비교 = 시간순) |
| 포맷 검증 | (없음) | 정규식 CHECK 2개 추가 |
| `updated_at` | (없음) | 추가 (수정 추적용) |

## §3 수정 — 헬퍼 시그니처 변경

본문 §3의 `getShiftSlotsForStaff(...): { startSlot: number; endSlot: number }`는 **폐기**. 확정 시그니처:

```ts
// src/lib/shiftResolver.ts
export interface StaffShiftOverride {
  staff_id: string;
  shift: 'open' | 'middle' | 'close';
  start_time: string;   // 'HH:MM'
  end_time: string;     // 'HH:MM'
}

export interface ShiftTime {
  startTime: string;    // 'HH:MM'
  endTime: string;      // 'HH:MM'
}

export function getShiftTimeForStaff(
  staffId: string,
  shift: 'open' | 'middle' | 'close',
  store: Pick<Store,
    | 'shift_open_start'   | 'shift_open_end'
    | 'shift_middle_start' | 'shift_middle_end'
    | 'shift_close_start'  | 'shift_close_end'
  >,
  overrides: StaffShiftOverride[],
): ShiftTime {
  // 1순위: 개인 오버라이드
  const o = overrides.find(x => x.staff_id === staffId && x.shift === shift);
  if (o) {
    return { startTime: o.start_time, endTime: o.end_time };
  }
  // 2순위: 매장 기본값 (stores 테이블의 인라인 컬럼)
  return {
    startTime: store[`shift_${shift}_start`],
    endTime:   store[`shift_${shift}_end`],
  };
}
```

**이름도 변경**: `getShiftSlotsForStaff` → **`getShiftTimeForStaff`** (반환이 슬롯 아닌 시간).
